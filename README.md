* Clone project.
* Install packages- pnpm install or npm install
* Build project: pnpm run build or npm run build
* Run project: pnpm run dev or npm run dev
* Run tests: pnpm run test or npm run test

** Incase of legacy peer dependency error run command < npm install --legacy-peer-deps>
** Incase you are running in your personal Pc and run into permissions issue, try < sudo npm install --legacy-peer-deps> or sudo with any other command.
